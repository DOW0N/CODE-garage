# Insight World Cup 기획 문서

월드컵 토너먼트를 기반으로 한 정보 분석 및 배팅 게임.
플레이어는 정보 카드로 국가를 분석하고 칩을 배팅하며, **우승국과 3위 국가를 예측해 맞히는 것**이 목표다.

## 기본 규칙

- 32개국, 32강 → 16강 → 8강 → 4강 → 3위전 · 결승
- 경기 승패는 게임 엔진이 국가별 내부 전력(비공개)과 랜덤 요소로 자동 결정
- 플레이어 최대 10명, 시작 칩 30개, 시작 시 B등급 정보 카드 1장 지급

## 정보 카드

| 등급 | 수량 | 구매 비용 |
|---|---|---|
| S | 5장 | 7칩 |
| A | 20장 | 5칩 |
| B | 30장 | 3칩 |

- 실제 승부 예측에 도움이 되는 명확한 근거를 담는다.
- 특정 국가 하나가 아니라 여러 국가·매치업에 활용할 수 있어야 한다.
- 구매한 플레이어만 볼 수 있다. 카드에 숨겨진 효과는 없다.

| 라운드 | 경기 | 경기 수 | 배팅 기회 |
|---|---|---|---|
| R1 | 32강 1~4경기 | 4 | 전반 전 + 하프타임 |
| R2 | 32강 5~8경기 | 4 | 전반 전 + 하프타임 |
| R3 | 32강 9~12경기 | 4 | 전반 전 + 하프타임 |
| R4 | 32강 13~16경기 | 4 | 전반 전 + 하프타임 |
| R5 | 16강 1~4경기 | 4 | 전반 전 + 하프타임 |
| R6 | 16강 5~8경기 | 4 | 전반 전 + 하프타임 |
| R7 | 8강 전체 | 4 | 전반 전 + 하프타임 |
| R8 | 4강 전체 | 2 | 전반 전 + 하프타임 |
| R9 | 3위전 | 1 | 전반 전 + 하프타임 |
| R10 | 결승 | 1 | 전반 전만 |

- 합계: 32경기, 배팅 기회 19회
- 배팅 기회마다 최대 3칩. 한 경기에 몰거나 여러 경기에 나눠 걸 수 있다.

## 경기 스코어 (확정)

- 전반전 스코어 → 하프타임 배팅 → 후반전 스코어 → 최종 결과
- 스코어는 양 팀 전력을 바탕으로 생성
- **무승부·승부차기 없음.** 후반 종료 시 동점이면 "후반 추가시간 결승골"이 들어간다.
  - 결승골을 넣는 팀은 전력 차이에 따른 확률로 결정
  - 예: 전반 1:0 → 후반 종료 1:1 → 추가시간 결승골 2:1

## 배당률 (방향만 확정, 공식 미정)

다음 요소에 따라 변동한다.

- 국가 기본 전력, 네임밸류
- 배팅한 플레이어 수, 해당 국가에 걸린 총 칩 수 (많이 걸릴수록 배당 하락)
- 전반전 결과에 따른 후반전 배당 변화

## 최종 예측과 승리 조건 (확정)

- **1차 예측:** R5 시작 전, 우승국 + 3위 국가 제출
- **예측 변경:** R8 시작 전
  - 그대로 유지하면 무료
  - 바꾸면 항목당 5칩 (우승국 변경 5칩, 3위 변경 5칩)
- **순위:**
  1. 우승국 + 3위 둘 다 맞힘
  2. 우승국만 맞힘
  3. 3위만 맞힘
  4. 둘 다 틀림
- 같은 등급 안에서는 칩을 많이 가진 사람이 높은 순위
- 칩까지 같으면 공동 우승

## 개발 원칙

- 디자인보다 기능 구현 우선 (디자인은 마지막)
- 한 단계씩 구현하고 실행해서 확인한 뒤 다음 단계로
- 수정할 파일의 정확한 경로와 전체 코드를 제공
- 기존 코드와 타입을 확인한 다음 수정
